# LootTestTask

Тестовое задание, вариант 1: лут, инвентарь и разборка.

Предметы лежат в ScriptableObject (имя, категория, вес, размер стопки, из чего разбирается, как подбирается). Инвентарь ограничен весом, лишнее не влезает, на маркере лута вес подсвечивается красным. 

Часть предметов подбирается автоматически, часть по нажатию. Над лутом в радиусе висят экранные маркеры. Из инвентаря можно выкинуть предмет или разобрать хлам на компоненты.

Unity 6000.3.28f1. 

### Архитектура

Данные предметов - ScriptableObject (ItemSO). На каждом объекте лута в сцене висит WorldItem со ссылкой на эти данные. У игрока компонент Inventory (список слотов и макс. вес) и ItemCollector (зона вокруг игрока: предметы рядом, подбор предмета).

Скрипты UI только отвечают только за визуал: маркеры над лутом, окно инвентаря, кнопки выброса и разборки. Сами операции вызывают Inventory.

InputManager читает клавиши из Input System и отдает их остальным скриптам (движение, подбор, открытие инвентаря). Когда инвентарь открыт, GameplayLock выключает камеру от мыши, ходьбу и подбор, чтобы кликать по UI.

### Управление:

- WASD - ходить, мышь - камера
- E - подобрать (если у предмета ручной подбор и камера смотрит на предмет)
- I или Q - инвентарь
- Клик по слоту в инвентаре - выброс / разборка
- R - перезагрузка сцены (для отладки)
- H - показать или спрятать курсор
